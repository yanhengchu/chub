# Maintenance Scripts

These are canonical fixed scripts for independent service actions and the system-upgrade oneshot. They retain only Chub-specific sequencing, deferred-restart handling, state cleanup, and final health checks; every fixed `launchctl` or `systemctl` operation is delegated to `scripts/platform/service-management.sh`. The upgrade-start action refreshes and reloads an inactive oneshot definition before triggering it, so a removed legacy path cannot remain cached in an installed service. Recovery first detects an active executor and leaves it untouched; it only reloads and starts an inactive executor. Invoke them through `chub` or their fixed Chub callers. Root-level legacy maintenance paths are not provided.
